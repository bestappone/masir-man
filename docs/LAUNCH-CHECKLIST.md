- [ ] Worker منتشر شده و `/api/health` پاسخ می‌دهد
- [ ] `ALLOWED_ORIGINS` درست است
- [ ] جداول و داده‌ی پایه ساخته شده (۱۳۵ رشته، ۱۸۴ شغل، ۸ آزمون)
- [ ] مدیر اول ساخته و `SETUP_KEY` حذف شده

**محتوا**

- [ ] مشاوران نمونه حذف/جایگزین شدند
- [ ] بنر نمونه خاموش یا واقعی است
- [ ] متن حریم خصوصی و قوانین توسط فرد ذی‌صلاح بازبینی شد
- [ ] ظرفیت/گروه آزمایشی رشته‌های مهم با دفترچه‌ی سنجش امسال تطبیق داده شد

**آزمون دستی روی سرور واقعی**

- [ ] فیلتر رشته‌ها (گروه، تیپ) و باز شدن چند صفحه‌ی رشته و شغل
- [ ] درخواست مشاوره ← پرداخت ← تأیید مدیر ← فعال شدن
- [ ] کاربر زیر ۱۸ سال و رضایت والد
- [ ] نصب PWA روی موبایل و نمایش راست‌به‌چپ
- [ ] پشتیبان‌گیری از دیتابیس
