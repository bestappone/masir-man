# بخش الف — به‌روزرسانی سایتِ در حال کار (نسخه‌ی v2)

⏱ حدود ۱۵ دقیقه. هیچ داده‌ای پاک نمی‌شود.

## گام ۱ — فایل به‌روزرسانی را آماده کن
1. فایل **`masir-man-UPDATE-v2.zip`** را روی کامپیوتر دانلود کن.
2. روی آن **راست‌کلیک ← Extract All** (در مک: دوبار کلیک) تا یک پوشه باز شود.
3. داخل پوشه‌ی بازشده باید این‌ها را ببینی: `frontend`، `worker`، `tools`، `docs`.

> ✅ این بسته عمداً **دو فایل حساس را ندارد** تا تنظیمات واقعی تو خراب نشود:
> `frontend/config.js` (آدرس API تو) و `worker/wrangler.toml` (اتصال دیتابیس تو).
> پس هرگز نسخه‌ی این دو فایل را از جای دیگری روی فایل‌های خودت نریز.

## گام ۲ — آپلود روی GitHub
1. برو به `https://github.com/bestappone/masir-man` (وارد حسابت باش).
2. دکمه‌ی **Add file ← Upload files** را بزن.
3. پوشه‌های داخل پوشه‌ی بازشده (`frontend`، `worker`، `tools`، `docs`) را **با موس بکش و داخل کادر صفحه رها کن**.
   - صبر کن تا نوار آپلود کامل شود (تعداد فایل‌ها کمتر از ۱۰۰ است و مشکلی ندارد).
4. پایین صفحه، در کادر **Commit changes** بنویس: `نسخه ۲` و مطمئن شو گزینه‌ی **Commit directly to the main branch** انتخاب است.
5. **Commit changes** (دکمه‌ی سبز) را بزن.

> اگر پیام «فایل‌های هم‌نام وجود دارند» دیدی طبیعی است؛ GitHub خودش جایگزین می‌کند.

## گام ۳ — سایت خودش به‌روز می‌شود
1. در همان مخزن روی تب **Actions** برو.
2. بالای لیست، اجرای «Deploy frontend to GitHub Pages» را ببین:
   - 🟡 نارنجی = در حال کار (۱ تا ۳ دقیقه صبر کن)
   - ✅ سبز = تمام شد
   - ❌ قرمز = به بخش «اگر مشکل پیش آمد» پایین بنگر.

## گام ۴ — Worker (بخش API) را به‌روز کن
**حالت ۱ — اگر Worker قبلاً به GitHub وصل است (Connect to Git):**
1. وارد **Cloudflare ← Workers & Pages ← masir-man-api** شو.
2. تب **Deployments** را باز کن. بعد از چند دقیقه یک ردیف جدید با زمان همین الان می‌بینی که وضعیتش **Success** است. تمام. به گام ۵ برو.

**حالت ۲ — اگر Worker وصل به GitHub نیست (ساده‌ترین راه: همین حالا وصلش کن):**
1. **Cloudflare ← Workers & Pages ← masir-man-api ← Settings ← Build** (در بعضی نسخه‌ها «Builds»).
2. **Connect** (یا Connect to Git) را بزن و GitHub را مجاز کن، مخزن `masir-man` را انتخاب کن.
3. در **Root directory** بنویس: `worker` و ذخیره کن.
4. اگر پرسید «Build command» را خالی بگذار؛ «Deploy command» را همان مقدار پیش‌فرض (`npx wrangler deploy`) بگذار.
5. **Save** و بعد **Deployments** را نگاه کن تا Success شود.

> ⚠️ هر دو متغیر `ALLOWED_ORIGINS` و `database_id` که قبلاً در `wrangler.toml` یا تنظیمات Cloudflare گذاشته‌ای دست‌نخورده می‌مانند. چیزی را در **Settings ← Variables and Secrets** پاک نکن.

## گام ۵ — دیتابیس را به‌روز کن (فقط چند کلیک)
1. برو به `https://bestappone.github.io/masir-man/admin/` و با حساب مدیر وارد شو.
2. در منوی کناری روی **⬆️ به‌روزرسانی دیتابیس** کلیک کن.
3. دو مورد را می‌بینی. کنار هرکدام دکمه‌ی **اجرا** را بزن:
   - `advice_text_v1` ← متن مشاوره‌ای اختیاری برای دسته‌های نتیجه‌ی تست
   - `konkur_pick_v1` ← ماژول انتخاب رشته‌ی کنکور
4. بعد از هر کدام باید «انجام‌شده ✓» ببینی. (اگر دوباره اجرا کنی ضرر ندارد.)

## گام ۶ — سایت را تازه کن و امتحان کن
1. در کامپیوتر: روی سایت `Ctrl + Shift + R` (مک: `Cmd + Shift + R`).
   در گوشی: مرورگر را کامل ببند و دوباره باز کن.
2. این سه چیز را امتحان کن:
   - ✅ یک تست را انجام بده ← بالای نتیجه باید کارت **«نتیجه‌ی تو، به زبان ساده»** ببینی.
   - ✅ منوی **مسیر من** ← اول صفحه کارت **«مسیرت، به زبان ساده»**.
   - ✅ منوی **انتخاب رشته‌ی کنکور** ← راهنمای ۶ مرحله‌ای باید باز شود.

# بخش ب — نصب از صفر (برای سایت جدید)

به سه چیز نیاز داری: حساب **GitHub**، حساب **Cloudflare** (هر دو رایگان) و یک ایمیل.

## گام ۱ — مخزن GitHub
1. در GitHub: **+ (بالا راست) ← New repository**. نام: `masir-man`. نوع **Public**. **Create repository**.
2. فایل کامل `masir-man-production-v2.zip` را Extract کن.
3. در صفحه‌ی مخزن: **uploading an existing file** (لینک وسط صفحه) را بزن.
4. همه‌ی محتوای پوشه‌ی بازشده را بکش و رها کن؛ **Commit changes**.

## گام ۲ — دیتابیس
1. Cloudflare ← **Storage & Databases ← D1 ← Create database**. نام: `masir-man-db` ← Create.
2. **Database ID** را کپی کن (یک متن طولانی).

## گام ۳ — دو تنظیم در فایل‌ها (در خود GitHub ویرایش کن)
1. در مخزن روی `worker` ← `wrangler.toml` کلیک کن ← آیکن ✏️ (Edit).
   - به‌جای `PUT-YOUR-D1-DATABASE-ID-HERE` شناسه‌ی گام ۲ را بگذار.
   - به‌جای `YOUR-USERNAME` نام کاربری GitHub خودت را بنویس. مثال: `https://bestappone.github.io`
   - **Commit changes**.
2. `frontend` ← `config.js` ← ✏️ ← بعد از ساخت Worker (گام ۴) مقدار `API_BASE` را آدرس Worker بگذار ← Commit.

## گام ۴ — Worker (API) از طریق Git
1. Cloudflare ← **Workers & Pages ← Create ← Import a repository** (یا Connect to Git).
2. GitHub را مجاز کن و `masir-man` را انتخاب کن.
3. **Project name:** `masir-man-api` — **Root directory:** `worker` ← **Save and Deploy**.
4. بعد از Success، آدرس Worker را کپی کن (شبیه `https://masir-man-api.xxxx.workers.dev`) و در `frontend/config.js` بگذار (گام ۳-۲).
5. در **Settings ← Variables and Secrets ← Add**:
   - نام `SETUP_KEY`، نوع **Secret**، مقدار: یک رمز طولانی تصادفی (آن را یادداشت کن).
   - نام `SESSION_DAYS`، نوع Text، مقدار `7` (اگر نبود).
6. اگر اتصال دیتابیس نشان داده نشد: **Settings ← Bindings ← Add ← D1 database**، نام `DB`، دیتابیس `masir-man-db`.

## گام ۵ — سایت (GitHub Pages)
1. مخزن ← **Settings ← Pages**.
2. بخش **Build and deployment ← Source** را روی **GitHub Actions** بگذار.
3. تب **Actions** را ببین تا سبز شود. سایت در `https://USERNAME.github.io/masir-man/` است.

## گام ۶ — ساخت جداول و مدیر
1. برو به `https://USERNAME.github.io/masir-man/admin/#/setup`
2. `SETUP_KEY` را وارد کن ← **ساخت جداول و داده‌ی نمونه**. اگر وسط کار قطع شد دوباره بزن؛ ضرر ندارد.
3. در گام دوم نام، ایمیل و رمز مدیر را بنویس.
4. **خیلی مهم:** برگرد به Cloudflare ← Settings ← Variables ← `SETUP_KEY` را **Delete** کن.

## گام ۷ — تنظیمات اولیه در پنل مدیریت
- **تنظیمات پرداخت:** شماره‌ی کارت واقعی خودت.
- **تنظیمات سایت:** نام، تماس، شهرها، پایه‌ها.
- **بنر تبلیغاتی و مشاوران نمونه:** حذف یا ویرایش.
- **هوش مصنوعی:** فقط اگر خواستی؛ کلید را در Cloudflare به‌صورت Secret با نام `AI_API_KEY` بگذار.

# بخش پ — انتخاب رشته‌ی کنکور: ورود داده و پولی/رایگان کردن

## پ-۱. ورود داده‌ی رشته‌محل‌ها (یک‌بار در سال)
بدون داده، صفحه فقط راهنمای مرحله‌ای و متن مشاوره‌ای نشان می‌دهد. برای تحلیل واقعی داده لازم است. داده را **فقط از دفترچه‌ی رسمی سازمان سنجش و آمار رتبه‌ی قبولی‌های منتشرشده** بردار؛ عدد حدسی نگذار.

**ساخت فایل داده بدون کدنویسی:**
1. در **Excel** یا **Google Sheets** یک جدول بساز. ردیف اول دقیقاً این سرستون‌ها (انگلیسی):
   `code | group_name | field_name | university | city | course_type | major_slug | capacity | rank_r1 | rank_r2 | rank_r3 | rank_year`
2. هر ردیف یک رشته‌محل:
   | ستون | معنی | مثال |
   |---|---|---|
   | code | کد رشته‌محل (یکتا) | 101 |
   | group_name | گروه آزمایشی | ریاضی |
   | field_name | نام رشته | مهندسی کامپیوتر |
   | university | دانشگاه | دانشگاه نمونه |
   | city | شهر | تهران |
   | course_type | نوع دوره | روزانه |
   | major_slug | (اختیاری) نشانی رشته‌ی متناظر در سایت | computer-engineering |
   | capacity | (اختیاری) ظرفیت | 30 |
   | rank_r1/2/3 | آخرین رتبه‌ی قبولی در منطقه‌ی ۱/۲/۳ (اگر ندارد خالی) | 3800 |
   | rank_year | سال داده | 1404 |
3. **File ← Save as / Download ← CSV (UTF-8)**.
4. فایل را با **Notepad** (یا TextEdit) باز کن، **همه‌ی متن را کپی کن** (`Ctrl+A` سپس `Ctrl+C`).
5. در پنل مدیریت: **🎓 ورود داده‌ی کنکور** ← متن را در کادر بچسبان ← **وارد کن**.
6. پیام «… ردیف وارد/به‌روز شد» را می‌بینی. ردیف‌های ناقص رد می‌شوند و بقیه ثبت می‌شوند.
- هر بار تا ۳۰۰۰ ردیف؛ برای بیشتر، در چند نوبت وارد کن.
- ورود دوباره‌ی همان کد، ردیف را **به‌روز** می‌کند و تکراری نمی‌سازد.
- اصلاح یک ردیف: منوی «رشته‌محل‌های کنکور (انتخاب رشته)» ← کلیک روی ردیف ← ویرایش.
- مخفی کردن یک ردیف: تیک **is_active** را بردار.

> 💡 `major_slug` را از آدرس صفحه‌ی همان رشته در سایت بردار: `…/#/majors/computer-engineering` ← بخش آخر.
> وقتی پر باشد، رشته‌های مورد علاقه‌ی کاربر در لیست بالاتر می‌آیند.

## پ-۲. پولی یا رایگان کردن
1. پنل ← **ویژگی‌های پولی (غیر از آزمون)**.
2. ردیف **konkur_pick** را باز کن:
   - **is_paid = بله** و **price = مبلغ به تومان** ← ذخیره = پولی
   - **is_paid = خیر** ← رایگان
3. فقط **تحلیل شخصی و چیدمان لیست** قفل می‌شود؛ راهنمای ۶ مرحله‌ای همیشه برای همه باز است.
4. وقتی کاربر می‌خرد، پرداخت کارت‌به‌کارتش در **✅ صف بررسی** می‌آید؛ تأیید کنی، دسترسی‌اش باز می‌شود (مثل مشاوره).

## پ-۳. نوشتن متن مشاوره‌ی اختصاصی برای هر دسته‌ی تست (اختیاری)
1. پنل ← **دسته‌بندی نتیجه‌ی تست** ← یک دسته را باز کن.
2. در فیلد **advice_text** با لحن دوستانه، چند جمله درباره‌ی آن دسته بنویس (مثلاً: «تو دوست داری بفهمی چیزها چطور کار می‌کنند…»).
3. ذخیره. از این به بعد همین متن در نتیجه‌ی کاربر به‌جای توضیح کوتاه می‌آید.
4. اگر فیلد خالی بماند، متن خودکار سایت استفاده می‌شود.
- اگر فیلد `advice_text` را در فرم نمی‌بینی، یعنی گام ۵ بخش الف (به‌روزرسانی دیتابیس) هنوز انجام نشده.

# اگر مشکل پیش آمد

| مشکل | کار ساده |
|---|---|
| Actions قرمز شد | روی آن کلیک کن ← **Re-run all jobs**. اگر باز قرمز بود، پیام را کپی کن و برای من بفرست. |
| سایت تغییر نکرد | `Ctrl+Shift+R`؛ بعد ۵ دقیقه صبر کن و دوباره Actions را ببین. |
| صفحه سفید یا «خطای ارتباط» | `frontend/config.js` را در GitHub باز کن؛ `API_BASE` باید دقیقاً آدرس Worker تو باشد (بدون `/` آخر). |
| «CORS» یا اجازه‌ی دسترسی نیست | Cloudflare ← Worker ← Settings ← Variables: `ALLOWED_ORIGINS` باید `https://bestappone.github.io` باشد (بدون `/` آخر). |
| در «به‌روزرسانی دیتابیس» خطا آمد | دوباره **اجرا** را بزن؛ امن است. اگر تکرار شد، متن خطا را برای من بفرست. |
| صفحه‌ی کنکور «لیست بارگذاری نشده» می‌گوید | طبیعی است؛ داده را طبق پ-۱ وارد کن. |
| رمز مدیر را فراموش کردم | مدیر دیگری از پنل می‌تواند رمز جدید بدهد؛ ایمیل خودکار نداریم. |
| خطای ۴۰۲ در تحلیل کنکور | یعنی آن بخش پولی است و کاربر هنوز نخریده؛ برای آزمون خودت می‌توانی `is_paid` را موقتاً خاموش کنی. |

## توصیه‌های ایمنی
- `SETUP_KEY` بعد از ساخت مدیر حذف شود.
- هیچ رمز یا کلیدی (مثل `AI_API_KEY`) داخل فایل‌های GitHub نوشته نشود؛ فقط در Cloudflare ← Secrets.
- قبل از هر به‌روزرسانی بزرگ، در GitHub مخزن را **Download ZIP** کن تا نسخه‌ی پشتیبان داشته باشی.
