# رفع اشکال

| نشانه | علت و راه‌حل |
|---|---|
| سایت «اتصال برقرار نشد» می‌دهد | `API_BASE` در `frontend/config.js` را بررسی کن؛ باید آدرس دقیق Worker باشد. |
| خطای CORS در کنسول مرورگر | `ALLOWED_ORIGINS` باید دقیقاً همان مبدأ سایت باشد (بدون `/` انتهایی، مثل `https://user.github.io`). |
| «SETUP_KEY هنوز ساخته نشده» | در Worker یک Secret به نام `SETUP_KEY` بساز و دوباره Deploy کن. |
| «دیتابیس D1 متصل نشده» | Binding با نام دقیق `DB` را اضافه کن. |
| راه‌اندازی وسط کار قطع شد | دوباره دکمه را بزن؛ اجرای مجدد بی‌خطر است. |
| «راه‌اندازی قبلاً انجام شده» | مدیر ساخته شده است؛ از صفحه‌ی ورود استفاده کن. |
| مهاجرت با wrangler خطا داد | فایل‌ها را به ترتیب اجرا کن یا از صفحه‌ی راه‌اندازی مرورگر استفاده کن. |
| پنل مدیریت ورود را رد می‌کند | فقط نقش مدیر/ویراستار وارد می‌شود. |
| تغییر سایت دیده نمی‌شود | کش Service Worker: صفحه را یک‌بار سخت‌رفرش کن یا نسخه‌ی کش را در `sw.js` بالا ببر. |
| «تعداد درخواست‌ها زیاد است» | محدودیت نرخ؛ چند دقیقه صبر کن. |
| دستیار هوش مصنوعی کار نمی‌کند | تنظیمات هوش مصنوعی را فعال کن و `AI_API_KEY` و آدرس/مدل را بررسی کن. |
| پیام «مرحله‌ی N با خطا مواجه شد» | متن خطا را بخوان؛ معمولاً Binding نادرست یا سقف حجم D1 است. |
