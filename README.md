# مسیر من (Masir Man)

پلتفرم فارسی راهنمای تحصیلی و شغلی برای دانش‌آموزان ایرانی:
**شناخت خود ← آزمون‌ها ← علاقه و توانایی ← رشته و شغل ← برنامه‌ی مسیر ← کوچینگ و مشاوره**

- **فرانت‌اند:** HTML/CSS/JS ساده (بدون build)، فارسی و راست‌به‌چپ، نصب‌شدنی (PWA) ← GitHub Pages
- **بک‌اند:** Cloudflare Workers + دیتابیس D1
- **پنل مدیریت:** `frontend/admin/` (مدیریت همه‌ی محتوا، مشاوران، پرداخت‌ها، تنظیمات)
 
## محتوای آماده  
| بخش | تعداد |
|---|---|
| رشته‌های دانشگاهی و مهارتی | ۱۳۵ (ریاضی، تجربی، انسانی، هنر، زبان، فرهنگیان، فنی‌وحرفه‌ای) |
| مشاغل | ۱۸۴ |
| آزمون‌ها | ۸ آزمون (۱۷۴ سؤال) با نتیجه و پیشنهاد رشته/شغل/مهارت |
| مهارت‌ها / دروس | ۳۷ / ۳۲ |
| فهرست‌های انتخابی | پایه‌ها، رشته‌های دبیرستان، ۳۳ شهر، گروه‌های آزمایشی |

همه‌ی این داده‌ها از پنل مدیریت قابل ویرایش، افزودن و حذف است.

## شروع سریع
مسیر بدون کدنویسی: **docs/NO-CODE-SETUP-GUIDE.md** — مسیر با خط فرمان: **docs/DEPLOY-GUIDE.md**

## ساختار
```
frontend/   سایت + admin/
worker/     API (src/) و مهاجرت‌ها (migrations/)
tools/      تولید داده‌ی اولیه (python3 tools/build_seed.py)
tests/      تست‌های خودکار
docs/       راهنماها
```

## آزمایش
```
node --experimental-sqlite --no-warnings tests/api.test.mjs
node --experimental-sqlite --no-warnings tests/admin_smoke.mjs
node --experimental-sqlite --no-warnings tests/frontend_smoke.mjs
```
(نیاز به Node 22 یا بالاتر.) این تست‌ها روی دیتابیس محلی اجرا می‌شوند؛ آزمون واقعی روی حساب Cloudflare خودت باید انجام شود (**docs/LAUNCH-CHECKLIST.md**).

## نکته‌ی مهم درباره‌ی محتوا
متن رشته‌ها و مشاغل **راهنمای کلی و بدون آمار ادعایی** است. ظرفیت، ضرایب و گروه آزمایشی هر سال را از دفترچه‌ی رسمی سازمان سنجش آموزش کشور تطبیق بده، و متن‌ها را دوره‌ای از پنل به‌روز کن. این پلتفرم جایگزین مشاور انسانی نیست و نتیجه‌ی آزمون‌ها تشخیص قطعی نیست.
